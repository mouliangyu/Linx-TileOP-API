## 0.59 对照依据

操作范围更新依据 [PTO-C 0.59](https://linxisa.github.io/PTO-C/)，源码核对为 Linx-TileOP-API 0.59 分支 ae2984c5fdfd1586cacf74ffa61ec3dd528ce5f8。站点引用 ISA active 42067d0f2890b8c013a868bd1247ebc6437b3179。活动目录 119 项；旧目录 118 项增加 TLEA，原子 TSTORE 及 TIMG2COL 作为额外入口列出。Reader/Writer、动态片段描述及 GM 类型协议是本手册的新库设计。

补充语义核对使用 LinxISA 0.59.1（linx-isa 提交 `7c658a8ce0ff89c1a7e0dd6ca47c9858aa062b27`，引用 PTO 规范 `a89a53d48f5708328be609fe2e6296ac8bdb4bc2`）。TIMG2COL 布局/协作、indexed TLSU 形状/范围等已按该版本修正；具体核对范围见[覆盖记录](../TileOpManualCoverage.md)。逐重载进度记录在核对表中。

## 版本与阅读约定

公开头文件 `<common/pto_tileop.hpp>`，命名空间 `pto`。操作和参数依据以上固定的 0.59 源码与站点核对；旧 0.58.7 对照记录仅保留为修订历史。

本手册定义新的 TileOP 接口，逐操作说明普通 Tile、Reader 和 Writer 的合法角色。分片支持按各页合同定义。覆盖依据及排除理由见 [覆盖清单](../TileOpManualCoverage.md)。

所有示例为设备函数片段。已进行源码/规范对照及文档结构检查，**未编译示例、未运行硬件或数值测试**。实现与验证状态单独记录在覆盖清单中。数值 profile 的近似精度不由接口公式额外定义。

参数表中的 out 表示产生结果、in 表示读取已定义输入、in-out 表示读取并修改旧值。所有算子返回 void，除非具体声明明确给出返回类型；旧目标参与计算的情况按参数表标为 in-out。CELL 为 128 字节，容量、有效元素数、行索引和字节位移是不同单位。

## 规范依据

本手册以 LinxISA 0.59.1 的[规范锁定文件](https://github.com/LinxISA/linx-isa/blob/7c658a8ce0ff89c1a7e0dd6ca47c9858aa062b27/isa/v0.59/pto-spec.lock.json)及其引用的操作条款为依据。数值行为采用锁定的 [pto-hardware-numeric-0.59.1-ieee-v1](https://github.com/PTO-ISA/pto-spec/blob/a89a53d48f5708328be609fe2e6296ac8bdb4bc2/spec/hardware-conformance-profile.json)。各操作的专用类型、布局和编码条款与公共数值规则共同构成接口合同。Reader/Writer 和便利重载属于库设计，其参数映射按各操作页说明。
